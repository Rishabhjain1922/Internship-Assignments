# **Java Assignment - Comprehensive Java Programs**

## **Overview**
This project contains a collection of Java programs covering fundamental concepts such as:
- Basic Java (Area calculations, factorial, Fibonacci, patterns)
- Data Types and Operators
- Control Flow Statements (If-else, loops, prime number check)
- Arrays (Sorting, searching, averaging)
- String Manipulation (Reversing, vowel counting, anagrams)
- Advanced Topics (Interfaces, Abstract Classes, Exception Handling)

These programs provide a structured way to learn and apply core Java concepts.

## **Technologies Used**
- **Java** (Core Java features)
- **JDK** 8 or later (Recommended)
- **IDE**: Any Java-supported IDE (Eclipse, IntelliJ IDEA, VS Code)

## **How to Run the Program**
1. **Install Java** (if not installed)
    - Download and install the latest JDK from [Oracle JDK](https://www.oracle.com/java/technologies/javase-jdk11-downloads.html).

2. **Clone or Download the Repository**
   ```sh
   git clone https://github.com/Rishabhjain1922/Java_Assignment.git
   cd java-assignment
   ```

3. **Compile and Run**  
   Open the terminal or command prompt and navigate to the directory where the file is saved. Run the following:
   ```sh
   javac Java_Assign_1.java
   java Java_Assign_1
   ```

## **Features & Program Descriptions**
### **1. Basic Java**
- **Area Calculations**:
    - Circle, Rectangle, and Triangle (Three methods: base-height, Heron’s formula, trigonometry)
- **Even or Odd Checker**
- **Factorial Calculation**:
    - Recursive and Iterative
- **Fibonacci Series**:
    - Recursive and Iterative
- **Pattern Printing**:
    - Triangle and Square using loops

### **2. Data Types & Operators**
- **Difference Between Primitive and Reference Types** (Commented)
- **Demonstration of Arithmetic, Relational, and Logical Operators**
- **Temperature Converter**:
    - Celsius to Fahrenheit and vice versa

### **3. Control Flow Statements**
- **Prime Number Checker**
- **Largest of Three Numbers** (Using Ternary Operator)
- **Multiplication Table (Using For Loop)**
- **Sum of Even Numbers (Using While Loop)**

### **4. Arrays**
- **Calculate Average of Array Elements**
- **Bubble Sort Algorithm**
- **Linear Search Algorithm**

### **5. String Manipulation**
- **Reverse a String**:
    - Iterative, Recursive, and StringBuilder Methods
- **Count Vowels in a String**
- **Check if Two Strings are Anagrams** (Optimized O(n) solution)

### **6. Advanced Topics**
- **Interface and Abstract Class Example**:
    - Interface: `Vehicle`
    - Abstract Class: `Animal`
    - Implementations: `Dog`, `Car`
- **Exception Handling**:
    - `try-catch-finally` for safe division and error handling
